# <img src="media/icon.png" alt="Quadrants Icon" width="32" height="32"> Quadrants

An "importance matrix" (the Eisenhower matrix thing) dynamic editor.

You can add as many rows and columns as you want, and place stuff anywhere.

## Features

- Saves as Markdown, easy to edit in a pinch.
- Obviously can load what it saved.
- Where are the buttons, you ask? Long press outside of the diagram (in the borders) to make them appear or disappear. Why like this? Because I wanted to.
- Long press to add items to the diagram.
- Press the upper right "arrow" to add columns, lower right "arrow" to add rows.
- Click on the headers to rename them.
- You can start any item (or heading) with the name of an [:iconoir:](https://iconoir.com) icon, it will render after you finish editing.
- Press `c` while hovering on an item to change its color (same functionality as [pinta](https://github.com/rberenguel/pinta)) by pressing another (color) key.
- Press `backspace` while hovering on an item to delete it.
- Press `space` while hovering on an item to mark it (some sort of importance).
- Press `Cmd-k` while hovering on an item to add (or remove) a URL from it.
- Export will export a standalone (no dependencies) HTML version of the diagram you can share as a single file.
