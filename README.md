# <img src="media/icon.png" alt="Quadrants Icon" width="32" height="32"> Quadrants

A dynamic, grid-based canvas for organizing items. Inspired by the Eisenhower Matrix, but with the flexibility to add as many rows and columns as you need.

Use it as a calendar, to set up your weekend, to plan for world domination.

## Features

### General

- **Dynamic Grid**: Start with a single canvas and add rows and columns as needed.
- **Markdown Persistence**: Saves and loads diagrams in a human-readable Markdown format.
- **Standalone Export**: Export your diagram as a single, self-contained HTML file.
- **Icon Support**: Start any item or header text with an [:iconoir:](https://iconoir.com) icon name (e.g., `:book:`) to display it.

### Controls & Shortcuts

- **Toggle UI**: `Alt+Click` or long-press on the page background to show/hide the control buttons.
- **Toggle Theme**: Press `q` to switch between light and dark modes.

### Items

- **Create**: Long-press on the canvas to create a new item.
- **Delete**: Select an item and press `Delete` or `Backspace`.
- **Add/Edit Link**: Select an item and press `Cmd/Ctrl+k` to attach a URL.
- **Mark Item**: Select an item and press `Space` to toggle its 'marked' state.
- **Change Color**: Select an item, press `c`, then press a color key (`r`, `g`, `b`, `y`, `m`, `c`, `v`, `o`, `s`, `w`).
- **Adjust Font Size**:
  - `.` to increase font size.
  - `,` to decrease font size.

### Grid

- **Add Column**: Click the button on the top-right corner of the grid.
- **Add Row**: Click the button on the bottom-right corner of the grid.
- **Rename Headers**: Click on any row or column header to edit its title.
